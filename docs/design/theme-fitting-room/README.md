# 主题试衣间 / 第二版：统一主题与内嵌选择

直接打开 [index.html](index.html)，无需安装依赖或联网。未修改 ztermy 的实际配色。

- 10 套终端调色板来自本仓库 `src/core/config/TerminalThemeCatalog.cpp`，基于提交 `33ac5e0` 的静态快照。
- 候选界面根据终端背景派生一套表面色。正文、次要文字、输入框、浮层、焦点与强调色各有职责；默认保留紫色强调色。
- “对照当前搭配”模拟 Theme.qml 中同明暗模式下的主要配色规则，不模拟全部原生状态，也不是实际 Qt 截图。
- 三个场景：终端与侧栏、设置与内容页、浮层与状态。命令不执行，示例窗口不控制系统窗口。
- 点候选区域可定位调色项。颜色改动和备注留在当前页面内存，刷新会清空，请导出保存。
- “设计方案”包含 UI 字段和备注，是后续实现输入，不能直接导入当前应用。
- “终端主题”是现有应用接受的 JSON，不包含界面皮肤。当前调色器没有改变 16 个 ANSI 原色。

## 统一模式

- 跟随系统：分别指定浅色和深色主题。切换槽位可临时预览另一明暗，不改变模拟的系统状态。
- 固定主题：只使用所选整套主题，忽略系统明暗切换。
- 系统状态模拟可跟随浏览器 `prefers-color-scheme`，或手工选深/浅，用来验证两种模式。
- 悬停/键盘聚焦只改变大预览；点击/Enter/Space 更新草稿。主题模式面板只随已选草稿换色，不随悬停换色。
- 应用保存到本页内存，并结束临时预览、恢复模式规则；放弃更改同时恢复主题分配、强调色和区域调色。不会写入 ztermy，也不跨刷新保存。
- 内嵌卡片展示顶栏、侧栏、终端和强调色，无主题选择弹窗。宽屏左卡片右预览，窄屏先展示预览再展示卡片。
- 设计方案导出格式为 version 2，包含 mode、light、dark、fixed、accentMode 和相应主题的完整颜色数据。

`build/theme-fitting-room-previews/`，不进入版本控制。可通过
`PLAYWRIGHT_MODULE` 指定 Playwright 模块路径。截图脚本只检查此网页，不运行
ztermy 的编译和测试。

检查覆盖 10 套主题 × 3 个场景，以及浅/深槽位、悬停不改草稿、放弃/应用、键盘选择、系统切换、固定主题、对照、区域调色、两种导出和窄屏布局。

第一轮修正了浅色次要文字对比度，以及窄屏主题导航过长的问题。预览按纯色校样；Acrylic、Mica、终端透明合成和 Windows 字体效果，需候选获选后回到原生应用验证。

本轮范围是可选择的设计模型，不是完成主题专项或准许合入的结论。
