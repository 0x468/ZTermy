# Tab / Pane / Session 交互提案（待审批）

对应 [ADR 0119](../adr/0119-tab-pane-session-ownership-and-transfers.md)。本页是交互示例，
不是已实施功能；当前单窗格拖出仍沿用原有 QML 展示逻辑。

## 共同规则

- 按住窗格标题或 Tab 开始拖动；按钮、终端文本区、滚动条不触发结构拖动。
- 拖动超过阈值后显示轻量拖动标签、明确的目标预览和操作名称；未进入有效目标则取消，
  只有有意拖到应用窗口外的窗格/Tab 才显示“新窗口”目标。Esc 随时取消。
- 目标边缘 25% 为相应方向的拆分；目标中心为交换。高亮预览必须同时显示
  “左/右/上/下/交换”，不能只靠颜色猜测。无变化的同位投放不重建视图。
- 拖动只移动会话，不复制连接；“复制窗格”是独立按钮，启动新会话。
- 结构变化不拦截终端普通按键，不改变 Shell 补全、历史和行编辑。

## 路径示例

| 起点 → 终点 | 预期结果 | 取消或失败 |
|---|---|---|
| Tab T 中的 B → A 左边缘 | B 在 A 左边，A/B 原进程与 SSH 连接持续，B 获得焦点 | 容量/保存失败则 A/B 原位，焦点不变 |
| B → A 中心 | A/B 交换显示位置，`SessionId`、输入路由和标题仍各自对应原会话 | 同一窗格投放无变化 |
| B → Tab 栏空位 | 创建新 Tab U，B 的连接迁移到 U；若 T 已无窗格则关闭 T | Esc 或无效目标取消，不关闭 B |
| 单窗格 Tab T → 窗口外 | 新独立窗口接管 T；原窗口不再显示一个空的 T | 新窗口未建立则 T 留在原窗口 |
| 多窗格 Tab T → 窗口外 | 整个布局树和全部会话迁移到新窗口 | 超过窗口限制则提示并保留原状 |
| Tab U → Tab T 中的 A 边缘 | U 的整棵树作为 A 邻侧子树插入，U 从标题栏消失 | 合并后超过 8 窗格则拒绝，不部分移动 |
| 独立窗口 → 原窗口 Tab 栏 | 工作区回附为 Tab；若原 Tab 已不存在，不生成重复 Tab | 原窗口关闭时可选另一窗口或保留独立 |
| 点击“复制窗格” | 以同一 Profile/Shell 设置建新 Pane 和新会话，默认右侧 | 新建失败不影响原会话或布局 |

## 生命周期与边界示例

1. 关闭 A 窗格：只关闭 A 的会话；若是工作区最后一个窗格，连同该 Tab 关闭。
   拖动 A 离开不是关闭，不能触发 SSH 断开或后台停止队列。
2. 关闭含两个活动 SSH 会话的独立窗口：与关闭含这些 Tab 的主窗口使用同一
   明确确认策略；取消后会话和窗口保留。最小化进入正常 Windows 任务栏。
3. 拖动中 SSH 掉线或目标窗格关闭：取消本次结构事务，源会话保留其最新
   连接状态；绝不把输入发送给恰好占据旧几何位置的其他会话。
4. 正在输入中文或显示主机密钥/凭证确认时开始拖动：不立即改变归属；
   等组合输入结束再允许，或取消手势并给出简短提示。
5. 跨 100%/150% DPI 屏幕：预览坐标按目标窗口换算；落地后重新测量
   终端网格、字体和滚动条，不把旧像素尺寸当列/行数。
6. 应用重启：不宣称原 SSH 仍在线。保存的窗口/树位置恢复为安全意图，
   SSH 仍需显式重连；无效树仅隔离对应工作区，不删除其余 Profile。

## 待你决定的三项

1. **回附位置**：单窗格独立窗口回到原 Tab（若仍存在），还是总在原窗口
   新建 Tab？建议前者；原 Tab 已消失时新建。
2. **整 Tab 合并**：第一阶段就支持把多窗格 Tab 拖到另一窗格，还是先只支持
   单窗格 Tab？建议第二阶段再开放多窗格树合并，以降低第一次迁移的风险。
3. **关窗确认**：有活动会话时统一确认，还是沿用现有关闭策略？建议只在
   关闭窗口会结束活动会话时确认；纯移动、重附着不确认。

## 验收矩阵（实施前定义，不代表已经通过）

| 层次 | 必验事项 |
|---|---|
| 纯模型 | 交换、四边插入、子树合并、最后一叶、上限、同位、重复命令、失败回滚 |
| 会话 | `SessionId` 不变；复制才新增；移动期间 worker 数、SSH 连接数不变 |
| 输入 | 激活/非激活窗格、IME、快捷键、鼠标选择、粘贴、失焦与关闭竞态 |
| 视图 | 滚动位置、搜索/选择、快照、DPI/材质、最大化/恢复、拖动预览 |
| 持久化 | schema-7 迁移、断电式中断、未来版本拒绝、坏树隔离、隐私边界 |
| Windows | 独立任务栏、Alt-Tab、最小化、跨屏、Snap Layouts、重附着 |
