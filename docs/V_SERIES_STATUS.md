  文字闪烁能力；下述独立窗口和 Profile 图标设计项。涉及协议范围、窗口恢复
  行为的选择先确认，性能改动以关闭路径的测量和相关回归为依据。
- 已确认产品规则：本轮同时支持 Kitty 和 Sixel 图片协议；独立窗口布局随会话
  恢复，并提供独立开关；终端修改标题受开关控制，但手动命名始终固定优先，
  只有手动清空标题才解除固定并恢复默认/自动命名。
- 批量关闭 Tab 已改为一次最终布局通知和保存。动态 Release 同构建的两轮
  对照中，关闭 7/8 个本地 Tab：逐项关闭为 1068/1082ms，批量为 133/124ms；
  相关控制器回归和隔离生命周期检查通过。该结果只覆盖批量 Tab 关闭，不能
  代替单个大布局 Pane 关闭或其它后续能力的验收。
- 大布局关闭已补充 4/8 Pane 的单窗格及整工作区运行测量，确认主要开销在
  快捷键提示反复读取动作列表。复用动作展示数据后，8 Pane 关闭一个为
  30/32ms（此前 258/264ms），关闭整工作区为 62/58ms（此前 282/302ms）。
  快捷键修改、重置和语言切换的缓存失效已覆盖；详细范围见终端研究文档。
