# ADR 0117：侧栏表面与覆盖面板的展示契约

- 状态：Accepted（V5 专项前体验修复）
- 日期：2026-09-12
- 范围：占位侧栏、连接历史详情；不涉及 Tab/Pane/Session 归属重构。

## 问题与决策

旧详情是宽度由 0 增长的 Rectangle，导致正文逐帧重排，也没有外部关闭和
固定语义。直接保存行的 QVariant 投影会让详情停留在点击时的状态。

SidePanelSurface 只负责共用表面样式和必填可访问名称。TerminalWorkbench
仍由外部布局分配空间、ResizeGrip 控制宽度。AppSideDrawer 复用 Qt Popup
覆盖在宿主上方，不缩小宿主内容，不用会话控制器承担动画状态。

展示方式和固定状态是两回事。占位面板的关闭仍由原宿主负责；覆盖面板通过
`pinned` 禁止外部点击/Escape 自动关闭，显式关闭仍有效。`dismissBlocked`
则用于调用方的未保存编辑：同时阻止自动关闭、显式关闭和替换条目，并在
显式尝试时发出 `dismissalBlocked`。当前连接详情只读，不启用此阻挡。
不以全局 activeFocus 丢失关闭面板，避免子菜单或确认弹窗抢焦点时误关。

## 数据和动画

- `present(key, payload)` 展示或切换条目；`refresh(key, payload)` 只刷新数据。
- 使用稳定 ID，刷新记录时不重新播放切换动画。记录删除、过滤出列表或页面
  隐藏时关闭详情；固定不意味着继续保留已不存在的记录。
- 固定宽度最高 420 逻辑像素，受宿主宽度约束；内部 ScrollView 支持正文滚动。
- 单次进入/退出各为 Theme.motionMedium 的一半，目前各 90ms；完整条目替换
  总预算 180ms，关闭动画结束前保留旧正文。关闭全局动画时遵循 0ms。
- Qt 在列表鼠标按下时可先自动关闭 Popup，再在释放时触发行选择；此时保存
  最新待展示条目，旧退出完成后打开最新条目，不抢先把旧正文换成新正文。
- 固定状态下替换直接使用两段半时长动画；中途新请求从当前偏移继续，覆盖
  待展示目标，不排队播放所有历史点击。

## 验证与边界

`--side-drawer-smoke --data-dir <隔离目录>` 使用真实 QML 控件、Qt 鼠标事件与
合成连接记录；不会建立 SSH/Shell 会话或发送终端输入。覆盖宽度 1120/600、
不挤压列表、连续点击、中途替换、记录更新、固定/关闭、子菜单、阻挡和删除。
100%/150% 各自运行；截图及结果记入 V5 跟踪。系统 Escape 物理键盘与真实
编辑保存确认流程仍需专项验收，不能用只读详情测试声称已验证所有编辑器。

参考本机 Qt 6.8.3 `qquickpopup.cpp`：`setVisible` 在退出期间可被重新打开；
`CloseOnPressOutside` 不因点击另一个 Popup 而关闭当前 Popup。关闭与焦点
处理采用 Qt 原生机制，不再维护一套全局点击捕获器。
