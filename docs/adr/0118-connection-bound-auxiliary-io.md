# ADR 0118：终端辅助 I/O 绑定连接上下文

- 状态：Accepted（V5 缺陷修复）
- 日期：2026-09-13
- 不涉及 Tab/Pane/Session 跨容器所有权设计。

## 证据与决策

SSH 历史、终端附属 SFTP 和传输此前按 sourceProfileId 从当前 Profile 构造
请求。回归用例确认：保持旧终端后编辑 Profile，辅助请求的端口变成新端口。
另一个回归确认：旧 SFTP 已排队的主目录回调能在重连后覆盖新连接的主目录。

在 startSshConnection 和 attemptSshReconnect 的实际启动边界，绑定当次
连接的请求提供者。它固定 Profile、身份和路由快照，并校验生成请求的
主机/端口/用户名与实际 SSH 请求一致；不匹配时返回 unavailable，不静默
转向新 Profile。没有连接上下文的已恢复窗格也不能回退到可变 Profile。

历史读取、终端 SFTP、终端上传/下载/批传和 AI 发起的文件下载统一使用该
上下文。已经排队的传输持有原提供者，继续面向原目标；编辑 Profile 不改
已有任务目标。独立 Profile 任务及跨重启任务恢复沿用原有工厂语义，本次
不升级传输持久化或改变任务所有权。

## 生命周期

- 重连采用新的已保存配置并重新绑定；编辑 Profile 本身不影响现有会话。
- 重新绑定取消旧历史任务、递增结果代次、清理读入历史/会话捕获/未完成
  输入及待上传列表，清除旧目录状态并停止旧 SFTP，防止不同身份混合数据。
- 重新绑定取消当前内置 AI 回合和待执行 SFTP 工具状态，保留对话记录；
  不让旧工具调用继续使用新连接或无限等待被拒绝的旧回调。
- 所有 SFTP 回调先经共享 currentTab 检查：弱引用的来源实例必须仍等于
  该终端当前 SFTP 实例。覆盖主目录、状态、列表、操作结果和主机密钥提示。
  仅 disconnect 不能保证取消已经排队的回调，因此不作为唯一保护。

## 凭证与范围

不长期复制连接密码/口令，不向持久化状态写入秘密。凭证仍从现有安全存储
按捕获的引用获取。未保存临时凭证的连接不因此自动获得可复用密码副本。
提供者保留创建时选择的凭证存储；之后迁移并清理原存储时，旧连接的辅助
请求可能要求重新连接。后续若改善该体验，应保留固定目标与身份边界。

## 验证

`AppControllerTests::bindsRemoteRequestsAndHistoryToConnectionIdentity` 使用
临时配置、回环监听器和合成状态；不认证真实主机，不执行 Shell 命令。
覆盖 Profile 编辑不漂移、重连采用新身份、旧任务取消/结果拒绝、旧 SFTP
队列回调拒绝、已排队任务仍使用旧目标，以及缺失/不匹配上下文失败。
测试通过一个仅供测试的 friend peer 访问现有内部入口，没有新增产品可调用
接口或为了夹具接入外部 Agent。完整构建与运行时证据见 V5 跟踪文档。
