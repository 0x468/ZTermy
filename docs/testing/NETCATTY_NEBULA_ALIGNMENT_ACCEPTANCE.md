# Netcatty / Nebula 对齐功能验收清单

本清单用于产品所有者验收 `NEBULA_ALIGNMENT_PROGRAM.md` 已选范围。它只覆盖 ztermy 自有能力，明确不包含
外部 Agent/CLI、Git 面板、在线更新检测或第三方代码与资产复制。

## 1. 验收准备

- [ ] 使用独立 `--data-dir` 完成一次空配置启动，再使用日常配置完成一次兼容性启动。
- [ ] 准备一个密码主机、一个密钥主机、一个包含别名/Include/ProxyJump 的 OpenSSH config。
- [ ] 准备至少四个终端 Tab、一个长滚动缓冲区和一个可用 SFTP 的 SSH 会话。
- [ ] 分别检查浅色、深色主题及 100%/150% DPI。

## 2. 工作台数据中心

### 已知主机

- [ ] 系统和自选 `known_hosts` 可导入；普通、带端口和多算法记录显示正确。
- [ ] 搜索、删除、清空和从条目发起连接工作正常，冲突与不支持记录有明确计数。
- [ ] 哈希主机名、通配符和 marker 不会伪装成普通可连接主机。

### 钥匙串与身份

- [ ] 可新建/导入密钥和证书；导入文件复制到 ztermy 管理目录，并组合用户名与认证材料形成可复用身份。
- [ ] 相同密钥路径只形成一条密钥资产；多个身份或 Profile 通过引用共享它，不出现逐 Profile 的重复密钥卡片。
- [ ] Profile 可引用身份；旧 Profile 迁移后仍能连接，原凭证和外部密钥文件不丢失，Profile 文档不再重复保存密钥路径。
- [ ] 被引用项不能误删；删除受管密钥不会删除钥匙串目录之外的文件。

### 连接日志

- [ ] 成功、失败、中断和本地终端会话形成结构化记录，重启后仍可查看。
- [ ] 全文、日期、主机、收藏筛选和增量加载正常；详情阶段、原因和时长可信。
- [ ] 异常退出后的活动记录标为“已中断”，不会显示为仍在线。

## 3. 终端交互

### 选区快捷浮窗

- [ ] 向下拖选时浮窗优先位于选区下方；向上拖选时优先位于选区上方。
- [ ] 保留选区并滚动终端后，浮窗随选区按相同距离移动，不停留在旧屏幕坐标。
- [ ] 靠近上下边缘时浮窗会翻转或夹在可见区；空闲后淡化，悬浮时恢复清晰。
- [ ] 设置中的动作顺序、直接/更多分层和逐动作保留选区策略均即时生效。
- [ ] “隐藏浮窗”只影响当前选区；永久关闭开关在重启后保持。

### Tab 与 Pane

- [ ] 两个及以上终端 Tab 时，上一个/下一个按钮稳定显示并循环切换活动 Tab。
- [ ] 关闭任意一个 Tab 后，只要仍有至少两个 Tab，切换按钮不会消失或失效。
- [ ] 宽窗口中的 Tab 会自适应利用空白；窄窗口中保持最小可读宽度并进入横向滚动。
- [ ] Tab 栏滚轮可循环切换并把键盘焦点交给目标终端；超宽时仍可拖拽排序、边缘自动滚动和下拉激活。
- [ ] Pane header、拖拽分屏、调整大小、缩放和脱离窗口后状态一致且可恢复。

### 历史、补全和命令面板

- [ ] 命令历史跨重启可检索；同一候选不会因连续采样无限重复。
- [ ] Ghost text 和候选接受键不会把额外控制字符发送到终端。
- [ ] 命令面板支持搜索、键盘导航、执行和快捷键冲突提示。

## 4. 导入、文件与恢复

- [ ] OpenSSH config 导入正确处理 Host/HostName/User/Port/IdentityFile/ProxyJump 和有界 Include。
- [ ] 顶栏 SFTP 页面同时提供本地文件与当前 SSH 会话的远程浏览器；工作台侧栏不再重复放置“本地文件”。
- [ ] SFTP 页面可切换已连接 SSH 会话；本地路径插入终端及远程目录跟随保持正常。
- [ ] 工作区导出再导入后，Tab、Pane、标题和关联 Profile 保持一致。
- [ ] 损坏或反复崩溃的恢复记录进入隔离，不会造成启动循环。

## 5. 本地终端

- [ ] 设置 → 终端 → 默认本地终端可选择自动、PowerShell 7/5、CMD、Git Bash、Nushell 或 WSL。
- [ ] 不可用 Shell 有明确标记；刷新检测后列表更新，保存并重启仍使用所选默认值。
- [ ] “新建终端方式”菜单可以临时选择不同 Shell，且不会改写默认设置。
- [ ] 横向或纵向调整窗口时，终端文字不会先按旧纹理拉伸再恢复。
- [ ] Windows PowerShell 5 不显示裸露的 OSC 633 控制文本，中文和提示符正常。
- [ ] PowerShell/CMD/Nushell 等本地进程通过 `exit` 或 EOF 退出后出现明确结束面板，可直接关闭 Pane。
- [ ] Nushell 连续空回车的提示符保持相邻行；切换 Tab 前后行距一致。
- [ ] 从“+”菜单新建任意本地终端后，首次键盘输入直接进入新终端，无需额外单击。

## 6. 自动化门禁

- [ ] Debug 与 static Release 非联网 CTest 全部通过。
- [ ] static Release clang-tidy、C++/QML 格式、QML 质量、翻译、资产和代码结构门禁通过。
- [ ] 窗口、DPI、键盘、终端渲染和生命周期 runtime smoke 通过。
- [ ] 发版时 Portable ZIP、MSI、结构合同和 SHA-256 manifest 通过。
- [ ] SSH、AI 和端口转发真实主机测试仅在明确授权并提供测试目标时执行和记录。
