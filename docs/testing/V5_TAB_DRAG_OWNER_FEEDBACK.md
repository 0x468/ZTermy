## 最新修订：关闭直达、紫色强调色、Pane 拖拽接入（2026-09-13）

Owner 于 2026-09-13 手验后反馈“可以提交，没什么问题了”，批准提交本批改动。
该反馈记录人工验收结论，不代表本批重新运行了全量自动回归或完成整个架构专项。

以下新决定覆盖本页较早批次的关闭确认、整 Tab 投放描述。

- **关闭确认移除**：原生主窗口 Close 事件先等待 QML 确认，托盘退出也经过同一
  分支。现删除确认状态/回调/弹窗，主窗口、独立窗格和下拉列表关闭均直接执行；
  已配置的“关闭到托盘”仍保留，而托盘菜单“退出”直接退出。多行粘贴、主机密钥
  等其它确认不受影响。
- **默认强调色改为紫色**：暗色主题 `#A78BFA`、亮色主题 `#7C3AED`，同步调整
  hover/pressed/focus/选中背景变体。采用默认 ztermy 配色的已有设置直接生效；
  系统强调色、自定义色、已有 customAccent 值不覆写，因此不涉及存储 schema 变化。
  success 语义颜色仍为绿色。
- **恢复回附图标**：从 split-horizontal 恢复为 external-link，与脱离窗格一致。
- **Tab 拖动只排序**：去掉 Tab 的结构拖放 MIME 路径和拖出窗口脱离行为，保留
  标题卡片、排序和边缘滚动。拖到终端内容或窗口外不合并、不创建独立窗口。
- **Pane 标题拖动**：此前只有原生独立窗口移动使用插入/预览计算，而嵌入 Pane
  仍走叶子自己的 DropArea，且切换 Tab 会替换来源视图。现由主窗口持有鼠标捕获、
  来源 paneId 和标题卡片，复用 coordinator 的插入竖线、悬停切换与区域预览。
  窗格按钮不进入拖拽捕获范围，非标题点击继续传递给原终端和其它控件。
  Tab 间隙/加号插入，Tab 中部默认并排加入，Pane 中心交换、边缘拆分，拖出主窗口
  脱离；Escape 取消。移除 Tab/加号上的重复旧 DropArea 路由。

验证边界：仅格式化和静态 Release 编译，不执行 CTest、clang-tidy 或运行时验证。
现有运行检查中的“Tab 拖动合并”期望已改为“不改变两边布局”，旧关闭确认期望已移除；
这些检查本轮未运行。编译日志为 `build/v55-pane-drag-purple-build.log` 和
`build/v55-pane-drag-purple-final-build.log`。产物为
`build/validation/v55-20260913-purple-pane-drag/ztermy.exe`。

手验重点：按住 A 的 Pane 标题进入 B 的 Tab 中部，在不松手的情况下继续进入 B 的
Pane 边缘再松手；另外检查 A/B 间竖线插入、加号追加、Tab 拖到正文无副作用，
以及托盘退出不再弹确认。

## 问题、定位与修改

| 反馈 | 代码中发现的问题 | 修改方式 |
|---|---|---|
| Pane 拖动只有光标 | Drag proxy 是 1×1 的不可见 Item，没有可视跟随物 | 保留投放热点，另在 Overlay 层显示跟随鼠标的标题卡片，避开终端和 Tab 列表裁剪；Tab 拖动复用相同外观 |
| 独立窗口只能笼统回附 | 原生移动仅在松手时判断是否进入顶栏，没有持续命中位置或区分插入/合并 | WM_MOVING 提供持续位置；Tab 两端约 8px 为插入区，显示竖线；中部进入目标 Tab，默认并排加入；继续移入终端可按左右/上下预览合并；加号追加；移动窗口临时半透明便于看清目标 |
| Tab 和下拉列表切换失效 | 点击立即聚焦旧 viewport，主布局却延后更新，旧焦点可把激活状态切回；另有历史 Session ID 与原 Tab ID 相同，搬家后 Tab 操作优先解析 Session 会指向其它 Tab | 统一激活入口先更新目标布局，再延后聚焦；避免页面显隐重新激活旧 ID；现存工作区 ID 优先于历史 Session 别名，覆盖关闭、复制、重命名、批量关闭与排序 |
| 重命名无法立即打字 | 弹窗只调用 selectAll，没有给输入框主动焦点；排队的终端聚焦也可能抢回焦点 | onOpened 显式 forceActiveFocus 后全选；重命名打开期间禁止排队的终端聚焦 |
| 下拉关闭按钮没有背景反馈 | background 是空 Item，只改变叉号颜色/大小 | 添加默认透明、hover 填充、按下加深、键盘 focus 描边的圆角背景 |
| 独立窗格原生标题和操作过多 | Qt.Window 默认原生标题，且 detached 强制 Pane header 常显 | 去掉原生标题，保留 Windows frame metadata、DWM、边缘缩放；Pane 标题默认隐藏；右上角为显示标题、恢复、最小化、最大化/恢复、关闭，闲置隐藏、移入显示；显示标题后可拖动整个独立窗口 |

代码定位支持上述因果判断；本次不运行现场复现，具体交互效果由 owner 手验确认。
断开/失败提示仍位于 TerminalSplitNode 的 leaf 内，以该 leaf 的 sessionId 重连，
不是整个 Tab 的模态提示。转移保留原会话，不通过重连来搬移窗格。

## 本次边界与已批准规则

- **恢复按钮**：仍优先回到原 Tab（存在且可容纳），否则新建 Tab。
- **拖到插入竖线或加号**：明确建立独立 Tab，不走恢复按钮的原 Tab 合并规则。
- **拖到 Tab 中部或终端区域**：合并入指定目标，保留现有容量/IME/保存失败保护。
- 按本次要求，新增的独立窗口只接纳一个 Pane，不允许在其中复制、新建或合并
  更多 Pane；完整多 Pane Tab 仍可以在主窗口内拖入另一 Tab 的 Pane，不能整体
  拖出为新的多 Pane 窗口。历史多 Pane 窗口的已有数据不删除。
- 只有关闭会结束活动会话时才确认；窗口移动、插入、回附不弹确认。
- Escape/回到原位置取消原生移动时不提交预览；保存失败不销毁来源窗口。
- 没有加入窗口几何持久化、多 Tab 独立窗口或通用 command revision 协议。
