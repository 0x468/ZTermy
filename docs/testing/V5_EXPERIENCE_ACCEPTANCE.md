### 紧凑标题补充修复（2026-09-13）

- SFTP 使用 `TitlePageAction`，不是终端/设置共用的 `TerminalTabAction`；空标题仍占 RowLayout 的图标与文字间距。隐藏空文字、清除空标题间距，并把图标改成偶数 16px；定向几何检查曾测得 -0.5px，最终在 1120/600px 均为 0px，鼠标路径退出 0。
- 下拉 Tab 列表的关闭按钮因透明背景且图标颜色固定，hover/按下都无反馈。保留透明背景，hover/键盘焦点提亮图标，按下使用强调色并轻微缩小。需人工确认手感与不同主题对比度。
- 进入 V5.5 仅意味着写出待审设计；ADR 0119 和交互示例仍为 Proposed，不实施新的跨 Tab/窗口会话归属。

- 终端原始按键/补全/行编辑归 Shell；不重加应用内 Ghost text 或补全拦截。
- 本轮不共享不同终端的 Shell 会话，不因相同 Profile 合并输入或连接。
- 不提前实现跨 Tab/窗口拖放或引入第三方图标；当前通用终端图标仅用于顶栏收起态，Profile 图标后续单独设计。

  替代所有编辑器未保存确认流程的验证。
