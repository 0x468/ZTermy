# 图标资源与交互审查

`icon-review.html` 是 2026-09-29 工作区中 79 个接口 SVG 的离线审查快照，
不是运行时资产目录或自动替换清单。它内嵌当前资源、固定版本 Tabler
v3.35.0 候选和 MIT 许可；不依赖 CDN、不读写应用数据、不建立远程连接。
ztermy 品牌 SVG/ICO 不在替换范围。

直接用浏览器打开，或从仓库根目录运行：

```powershell
python -m http.server 8876 --bind 127.0.0.1 --directory docs/previews
```

访问 `http://127.0.0.1:8876/icon-review.html`。只服务此预览目录，不服务仓库根目录。
审查结果保存在浏览器 localStorage，可导出 JSON。无浏览器存储权限时使用导出。

每项包含用途、资源 ID、现有/候选对照、候选名、参考 QML 文件和个人意见。
参考文件仅是源码字符串匹配结果，不代表完整调用关系，也不证明未引用资源无用。
内存、硬盘、置顶窗口保留当前造型，另列语义冲突而不是强行选用错误图标。

交互展示的是待审设计，不代表应用已经实现：120ms 悬停反馈、70ms 轻微按下，
选中/焦点分离，复制完成回执，真实忙碌期间才持续旋转。减少动效与系统
prefers-reduced-motion 下停止旋转/缩放，保留文字状态。窗口按钮不缩放，
生产落地不能改动原生 Snap Layout 命中或窗口消息处理。

后续实施需以审查通过的语义映射为依据，再更新资源来源、CMake、图标检查、
相关 UI 与主题/键盘/缩放验证；不得将整个候选目录自动覆盖生产图标。
