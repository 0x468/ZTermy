01 / 状态，不靠图标跳动表达

可鼠标悬停、按住按钮，或用 Tab 查看焦点。这里的“复制”和“刷新”会给出一次性反馈。

复制 → 成功勾选 → 还原刷新仅在忙碌期间旋转
  • 悬停 120ms 明暗/底色变化；按下 70ms、最多 4% 收缩。窗口按钮不缩放。
  • 选中 = 强调色＋短标记；焦点 = 可见轮廓。两者不是同一个状态。
  • 危险色只用于删除语义；错误、忙碌、禁用不能只靠颜色区分。
  • 减少动效时取消旋转与缩放，仍保留“刷新中…”文字；不做常驻呼吸。

03 / 资源对照与逐项审查

左为当前资源，右为候选。统一为 20 单位网格、有效 1.5 描边；尺寸菜单可检查小图标。内存、硬盘、窗口置顶暂保留原形，避免错误语义。
